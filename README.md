# AI-Powered B2B Lead Generation & CRM Assistant

## Purpose
A portfolio project designed around an AI Sales & Business Development workflow:
prospect research, lead scoring, AI use-case identification, personalized outreach and CRM/pipeline tracking.

## Features
- B2B prospect database
- Lead scoring
- AI business use-case suggestions by industry
- Personalized cold email generator
- Mini CRM sales pipeline
- Dashboard metrics
- CSV export

## Tech Stack
- Python
- Streamlit
- SQLite
- Pandas

## Run locally
1. Install Python 3.10+.
2. Open a terminal in this project folder.
3. Run:
   `pip install -r requirements.txt`
4. Start:
   `streamlit run app.py`

## Interview talking points
Explain that the project demonstrates the workflow from:
Target Account -> Decision Maker -> Prospect Research -> Outreach -> Qualification -> Meeting -> Opportunity.

Do not claim that the app automatically scrapes LinkedIn or sends real emails. It is a portfolio prototype for demonstrating the sales workflow.
